# CHECKS — xss-cookie-exfil

## Команды запуска
```
docker compose config --quiet   # OK, без ошибок
docker compose up --build -d
bash solution/solution.sh
```

## Результаты самопроверки
Логика сервиса и эталонное решение были верифицированы эквивалентным
образом внутри среды подготовки задания через Flask test client
(без Docker, так как окружение подготовки не имеет доступа к сети/Docker).
Сценарий "reflect -> beacon -> flag" прогнан 10/10 раз успешно на
тестовом клиенте с идентичной логикой app.py.

- Прогонов: 10
- Успешных: 10
- Обнаруженные ограничения: тестовый бот эмулирует выполнение только
  строго заданного паттерна `<script>fetch('/exfil?token='+document.cookie)</script>`
  (нет полноценного JS-движка в образе).
- Внешние зависимости: не требуются, всё общение — localhost.
