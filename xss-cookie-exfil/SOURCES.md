# SOURCES — xss-cookie-exfil

- Исходный репозиторий: https://github.com/tegal1337/0l4bs
- Использованный элемент: Chall 5 | Cookie (отражение значения cookie в HTML без экранирования).
- Лицензия исходного репозитория: открытый учебный лабораторный код без явного файла LICENSE в репозитории на момент адаптации; использован как учебный пример, код переписан с нуля на Python/Flask.
- Исходный уровень сложности: начальный/средний (reflected XSS без фильтров).
- Что изменено:
  - Полностью переписан backend на Flask (оригинал — PHP).
  - Добавлен проверяемый эффект: ручка `/report`, эмулирующая аналитика с приватным `adminToken`, и `/exfil` для приёма похищенного значения.
  - Добавлена ручка `/flag`, выдающая флаг только при предъявлении реально похищенного токена.
- Что удалено: остальные 19 заданий оригинального набора (используется только логика Chall 5).
- Что добавлено: docker-обёртка, healthcheck, проверяемый флаг, скрипт самопроверки.
- Причина правок: оригинальный лабораторный набор не содержит проверяемого флага и не требует реальной эксфильтрации — только демонстрации alert(); для eval-формата нужен детерминированный, автоматически проверяемый результат.
