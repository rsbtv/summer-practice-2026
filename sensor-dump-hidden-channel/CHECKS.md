# CHECKS — sensor-dump-hidden-channel

## Команды запуска
```
bash solution/solution.sh
```
(без docker compose — задача не поднимает сервис)

## Результаты самопроверки
Скрипт самопроверки прогнан 10/10 раз подряд, каждый раз восстанавливает
идентичную строку `flag{modbus_dump_xor_channel_9f3a}`. Так как файл `capture.bin` статичен и
детерминирован (сгенерирован фиксированным seed=42 в генераторе задания),
результат не зависит от случайности при запуске решения.

- Прогонов: 10
- Успешных: 10
- Ограничения: решение работает только с фиксированным `resources/capture.bin`,
  предоставленным в комплекте задания.
- Внешние зависимости: не требуются, весь разбор — локальный (python3,
  стандартная библиотека).
